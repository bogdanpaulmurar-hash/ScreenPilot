# Release 0.9.3 — Clipboard choice for several areas, right in the selector

## User release notes
- **Switch before Enter**: with several areas selected (Ctrl), the bar next to them shows **One by one** / **One image**. Click it (or press **M**) to choose how the captures go to the clipboard, then press Enter or Copy.
- The choice is remembered: it is the same setting as *Settings › Capture › Several areas*.
- A second line at the top of the screen shows the current choice.
- If the setting is locked by your administrator, the switch is shown greyed out.
- Unchanged: the OK button on the scrolling pill (0.9.2).

## Technical release notes
- `ui.region_selector`: `CLIP_SEQUENCE` / `CLIP_COMBINED`; `ActionBar.clip_button`, `set_clip_mode()`, `clip_toggled`; `MonitorOverlay.clip_toggled` (key M with several regions); `RegionSelector.start(clip_mode=, clip_locked=)`, `toggle_clip_mode()`, `clip_mode_changed`; the multi status draws a second pill with the clipboard choice.
- `ui.controller`: passes `capture.multi_clipboard` (and its lock) to the selector and saves the switch.
- i18n: `selector.multi.clipboard.*` (EN + RO).
- Tests: three new `MultiCaptureUiTests` (click switch → one image, M back to one by one, hidden for one area / locked by policy).

## Checklist (Windows)
- [ ] Ctrl+drag two areas: the bar shows Capture, Copy, Edit, **One by one**, Cancel; the top shows "Clipboard: One by one".
- [ ] Click **One by one**: it becomes **One image**; Enter copies a single image with the areas one below the other.
- [ ] Next time the selector opens with **One image**; M switches back; Settings › Capture › Several areas shows the same choice.
- [ ] With one area only, the switch is not shown and M does nothing.
