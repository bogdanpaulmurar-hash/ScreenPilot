# Release 0.9.6 — Scrolling capture: no "shadow" behind the floating box

## User release notes
- **Fixed**: in a scrolling capture of a page with a floating input box (the Claude panel in VS Code), a faint copy of another section showed around the box at the bottom of the picture. The bottom now shows what is really at the end of the page.

## Technical release notes
- `ScrollStitcher.result()`: when a floating box was detected (`_footer`, 0.9.5), its block at the end of the picture is taken from the last frame instead of the first one. The first frame's block showed the page around and behind the box at the start of the capture.
- Test: `test_the_box_block_shows_the_end_of_the_page_not_the_start` (fails on 0.9.5).
