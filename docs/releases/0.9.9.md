# Release 0.9.9 — Editor: change step numbers

## User release notes
- **New**: in the image editor, **double-click a step badge** (or right-click it → **Change number…**) and type the number it should show. The steps after it continue from that number.
  - Wrong step? Give it the right number.
  - Start from another number? Change the first step (e.g. 5 → 5, 6, 7…).
- Right-click a step: **Automatic number** (this step counts normally again) and **Renumber all: 1, 2, 3…**.
- A duplicated step (Ctrl+D) takes the next number instead of repeating a fixed one. Ctrl+Z undoes a number change.

## Technical release notes
- Core (Qt-free): a step `Shape` keeps a hand-set number in `text` (empty = automatic). `EditorDocument.step_number()` counts from `step_start`, jumps to a fixed number when it meets one and continues from it. New `set_step_number(index, number|None)` (undoable, clamped to 0–999, `MAX_STEP_NUMBER`), `reset_step_numbers()`, helper `fixed_step_number(shape)`.
- Rendering: 3-digit labels use a smaller font so they fit the badge.
- UI: `EditorCanvas.edit_step_number()` (QInputDialog.getInt, starts at the current number), double-click on a step, step entries in the right-click menu (`EditorWindow.build_context_menu()`, split out of `_context_menu` so it can be tested without a modal menu). Duplicating a step clears its fixed number.
- New strings: `editor.step.number`, `editor.step.number.prompt`, `editor.step.auto`, `editor.step.renumber`; `editor.hint.step` / `editor.hint.select` mention the double-click (EN + RO). No new settings or dependencies.
- The separate "Number the steps" window (`editor/steps.py`, its own "Start at") and video-editor steps are unchanged.
