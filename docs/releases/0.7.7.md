# Release 0.7.7 — Editor v2 is back

The editor from the local 0.5.0 laptop build (never pushed) is restored and merged with everything added since (0.5.1–0.7.6).

## User release notes
- **Pictures in the editor**: insert other pictures on top of a capture.
  - From a file, the clipboard (Ctrl+V), recent captures, or by dropping files on the editor.
  - Move, resize with the handles (pictures keep their proportions; hold Shift to stretch), bring to front / send to back, duplicate, place below or to the right.
  - Useful for building a procedure image from several captures.
- **Handles on shapes**: rectangles, ellipses, highlights, blur, pixelate, spotlight and pictures have 8 handles; arrows and lines have one at each end. Drag a handle to resize (Shift keeps the proportions); drag the edge elsewhere to move.
- **Symbols and emoji** tool.
- **Full colour picker** with recent colours.
- **Zoom and pan**: Ctrl+wheel at the cursor (up to 800 %), Ctrl+= / Ctrl+-, Ctrl+0 fit, Ctrl+1 100 %.
- Kept from the newer versions: *Copy & close* (Ctrl+Shift+Enter, also keeps procedure edits), Esc closes after confirming, sharp 1:1 display at 125 % / 150 %, fast selector on Excel and Google Sheets.
- **Procedure › Edit image** now opens the editor in front, with keyboard focus.

## Technical release notes
- `editor.document`: `image` shapes with `EditorDocument.images` (ref → `CapturedImage`), `add_image()`, z-order helpers, `emoji` shapes with `emoji_font()` / `emoji_bounds()`, smoother shapes.
- `ui.editor_window`: `EditorCanvas.handles()`, `handle_at()`, `resized()` (MIN_SIZE, keep ratio); zoom/pan with device-pixel-ratio-aware fit scale (replaces `fit_target` in the editor).
- `AppController._procedure_edit_image` uses `present()`.
- Tests: `test_editor_document` covers pictures and emoji; `EditorTests.test_draw_tools_undo_select_move_and_done` now checks resize by the left-middle handle and move by the edge.

## Checklist (Windows)
- [ ] Editor › Insert picture › From recent captures: the picture appears on top, can be moved, resized by the corners (keeps the ratio; Shift stretches) and sent to back.
- [ ] Ctrl+V of a picture copied from another app inserts it; dropping a .png file inserts it.
- [ ] A rectangle can be resized after it was drawn (handles) and moved by its edge.
- [ ] Procedure › Edit image: the editor opens in front; Copy & close keeps the edit in the step.
- [ ] Windows scaling 150 %: the text in the editor is as sharp as on screen.
