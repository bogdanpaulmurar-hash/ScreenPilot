# Release 0.8.0 — Several captures at once (Ctrl)

## User release notes
- **Hold Ctrl in the selector to capture several areas** one after another, on any monitor.
  - Each area you finish with Ctrl held (drag, or click on a window) stays lit, outlined and numbered; draw the next one right away.
  - Backspace (or Ctrl+Z) removes the last area, a right-click removes the area under the cursor, Esc cancels everything.
  - **Enter** captures all of them (and the current selection, if any): each one is saved like a normal capture (history, folder), and they are copied to the clipboard.
  - **Clipboard**: by default one by one, so Windows' clipboard history (Win+V) shows every capture and the last one is ready for Ctrl+V. Or, in *Settings › Capture › Several areas*, as one image with the captures one below the other.
  - **Copy (Ctrl+C)** copies them without saving; **Edit (E)** opens the editor with the first capture as the background and the others as pictures below it, at their real size, ready to be moved, resized or deleted.
  - Pin, OCR, scrolling capture and the other single-area actions are hidden while several areas are selected.

## Technical release notes
- `capture.selection.RegionList`: ordered regions with `add`, `pop`, `remove_at`, `number`, `final(current)`.
- `capture.image.stack_offsets()` / `stack_images()` (headless, Pillow).
- `ui.region_selector`: shared `RegionList`; `MonitorOverlay.pressed` now carries the Ctrl state; `confirmed` / `RegionSelector.finished` report a `list[Rect]` for several regions; `SelectorStyle.multi`; `ActionBar.set_multi()`; `MULTI_ACTIONS`.
- `ui.controller`: `capture_many()`, `copy_many()` (sequence with `MULTI_CLIPBOARD_DELAY_MS` = 400 or combined), `open_editor_many()`.
- `ui.editor_window.EditorWindow.attach_below()`.
- New setting `capture.multi_clipboard` = `sequence` (default) / `combined`.
- Tests: `tests/test_multi_capture.py` (headless) and `MultiCaptureUiTests` in `tests/test_ui.py`.
