# Release 0.9.1 — Every shape can be adjusted after it is drawn

## User release notes
- **Adjust right after drawing**: a new rectangle, ellipse, highlight, blur, pixelate, spotlight, arrow or line stays selected, with its handles. Drag a handle to resize it without switching to Select (V) first. Shift keeps the proportions.
- **Click to select with any tool**: a plain click (no drag) on a shape selects it, even with a drawing tool active. Dragging elsewhere still draws a new shape. A click on empty space clears the selection.
- **Text, symbols and step numbers have handles**: four corner handles scale them; the opposite corner stays where it is. With the Text, Symbol or Step tool, a click on an existing one selects it instead of adding another.
- **Crop can be adjusted**: with the Crop tool, the kept area has eight handles (Shift keeps the proportions). Undo brings back the previous area.
- **Colour follows the selection**: selecting a shape shows its colour on the colour button.
- Unchanged: pictures in the editor (0.7.7), several areas with Ctrl (0.8.0), backup and restore (0.9.0).

## Technical release notes
- Editor v2 in `main` was compared with the laptop build it was restored from (0.7.7): `ui/editor_window.py` and `editor/document.py` match, plus the features added since. The laptop's "open in editor" menu is covered by `EditorPicker`. Three editor tests that only existed in the laptop build are ported.
- `editor.document`: headless handle geometry `box_handles()`, `resize_box()`, `scaled()` and `SCALED_KINDS` (text, emoji, step).
- `ui.editor_window.EditorCanvas`: handles of the selected shape work in every tool; drawn/placed shapes are selected; click-to-select with drawing tools; `crop_handles()` / `crop_handle_at()`; corner handles for scaled kinds; `EditorWindow._show_color()` syncs the colour button on selection.
- Tests: `HandleGeometryTests` (headless); `EditorV2Tests` gain handles for every kind, resize right after drawing, scaling text/symbols/steps, crop handles, colour sync, plus the ported zoom, canvas-growth and paste/symbol/colour/copy-close tests.
