# Release 0.9.8 — Procedure: one-image export and copy per step

## User release notes
- **New**: in the Procedure window, **Export → One image (.png)** saves all steps as one picture, one below the other. Above each image there is a line "Step N: title".
- **New**: **Copy image** for each step: the copy button under the preview, right-click on a step in the list, or **Ctrl+C** in the list. The image goes to the clipboard the same way as a capture (paste it in Word, Outlook, Teams, Excel).

## Technical release notes
- Core (Qt-free): `screenpilot.docs.export_image(session, target, *, step_label, headers=True)` with Pillow; images keep their size, aligned left, 24 px margin, 32 px gap, 44 px header; results longer than `IMAGE_MAX_SIDE` (60 000 px) are scaled down; an empty procedure raises `ValueError`.
- UI: `ProcedureWindow(copy_image=...)`; the controller copies through `app.clipboard` (DIB + PNG) and shows the usual "Capture copied" notification. Ctrl+C is taken from the list with an event filter (the list would otherwise copy its text).
- New strings: `procedure.export.png`, `procedure.copy_image` (EN + RO). No new settings, no new dependencies.
- Tests: `SingleImageExportTests` (layout and order, no headers, scaling, empty procedure); `test_record_procedure_edit_and_export_all_formats` covers PNG export and both copy paths.

## Checklist (Windows)
- [ ] Procedure with 3+ steps → Export → One image (.png): one PNG with all steps in order, titles above.
- [ ] Select a step → copy button: paste in Paint/Word gives that step's image.
- [ ] Right-click a step → Copy image; and Ctrl+C in the list: same result.
