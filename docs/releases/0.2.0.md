# Release 0.2.0 — Desktop shell (M1)

## User release notes

**New**
- ScreenPilot now runs in the system tray: `screenpilot-gui` (or `python -m screenpilot gui`).
- **Region capture** (`Ctrl+Shift+1`, or left-click the tray icon): the screen freezes,
  then drag to select, or click a window to snap to it. Magnifier with pixel
  coordinates and colour code. Resize with the handles, move by dragging,
  arrows to nudge (Shift = 10 px), Alt+arrows to resize, Enter to confirm,
  Esc / right-click to cancel.
- **Delayed capture** with an on-screen countdown (3 / 5 / 10 s from the tray,
  `Ctrl+Shift+5` uses the default delay). Open menus during the countdown —
  they will be in the capture.
- Window, current-monitor, all-monitors and repeat-last captures from hotkeys or the tray.
- Notifications after every capture (saved / copied / failed).
- **Settings** (no OK button — changes apply immediately): language, image
  format, JPEG quality, default delay, file-name template with live preview,
  save folder, after-capture actions (tick and drag to reorder).
- **Hotkey manager**: search, change, clear, conflict warnings (duplicates,
  Windows-reserved keys, keys taken by other apps), import / export profiles.
- **Capture history** with thumbnails: open, copy image, copy path, show in folder.
- **First-run wizard**: welcome, language, shortcuts, how it works.
- Everything switches between English and Romanian instantly.

**Known limitations**
- A region selection stays on one monitor (use "All monitors" for spanning captures).
- Editor, OCR and documentation export are not available yet (shown as "future version").
- The mouse cursor is not included in captures.

## Technical release notes
- New optional dependency group `ui` → `PySide6-Essentials` (reviewed in `docs/DEPENDENCIES.md`).
- `CaptureService.freeze()` / `region_from_frozen()`; `screenpilot.history`;
  toolkit-independent `capture.selection.SelectionModel`.
- `screenpilot.samples.DemoBackend` renders a synthetic desktop for demos/tests.
- Workflow runs on a single background worker; bus events are marshalled to
  the GUI thread through `EventBridge`.
- CI runs 16 offscreen QTest UI tests on Windows and publishes screenshots to
  the `ci-screenshots` branch.

## Test checklists

### Smoke test (5 min)
```
pip install -e ".[ui]"
python -m screenpilot gui
```
- [ ] Wizard appears on first start; finish it.
- [ ] Tray icon visible; tooltip shows `Ctrl+Shift+1`.
- [ ] `Ctrl+Shift+1`, drag a rectangle, Enter → notification, image pastes into Paint.

### Functional test (15 min)
- [ ] Region: click on a window → snaps exactly to the window (no shadow).
- [ ] Region: arrows / Shift+arrows / Alt+arrows behave as described; Esc cancels.
- [ ] Magnifier shows coordinates and colour; values match the screen.
- [ ] Delayed 5 s from tray: open a Start-menu or right-click menu during countdown → it is in the capture.
- [ ] Settings › Language → Română: tray menu, settings window and notifications change instantly.
- [ ] Settings › Hotkeys: assign `Ctrl+Shift+2` to "Capture region" → duplicate warning; restore defaults.
- [ ] Settings › After capture: untick "Save" → capture is only copied (notification "Capture copied").
- [ ] History: double-click opens the image; "Show in folder" selects it in Explorer.
- [ ] Start the app a second time → "already running" message.

### Full validation
- [ ] Two monitors with different scaling (e.g. 150 % + 100 %): selection and result are pixel-exact on both.
- [ ] Monitor left of / above the primary.
- [ ] 4K monitor: the selector opens in < 0.5 s and stays fluid.
- [ ] Another app already owns `Ctrl+Shift+3` → status "Not registered" + warning at startup.
- [ ] Export the hotkey profile, change keys, import it back.
- [ ] Portable mode (`portable.flag`) keeps settings, history and lock file under `UserData`.
