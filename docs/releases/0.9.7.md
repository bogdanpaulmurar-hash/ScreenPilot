# Release 0.9.7 — Editor "Copy & close" also saves the image

## User release notes
- **Changed**: in the image editor, **Copy & close** (Ctrl+Shift+Enter) now also saves the edited image to the captures folder, with the same file name pattern as other captures; it appears in the history. The image is still copied to the clipboard.
- **New setting**: *Settings → General → "Save on Copy & close"* (on by default). Turn it off to get the old copy-only behavior.
- The captures folder is *Settings → "Save to"*.

## Technical release notes
- New setting `editor.copy_close_saves` (default `true`).
- `Controller.open_editor` passes `on_copy_close=_editor_copy_closed`, which runs `process(result, [{"id": "save"}], quiet=True)` when the setting is on. The procedure step editor is unchanged.
- Tests: `CopyAndCloseTests` (saves + history; setting off saves nothing).

## Checklist (Windows)
- [ ] Editor → Copy & close: file appears in the captures folder, Ctrl+V still pastes the image.
- [ ] Turn the setting off: nothing is saved.
