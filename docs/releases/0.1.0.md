# Release 0.1.0 — Foundation (M0)

## User release notes

**New**
- Command-line capture: region, active window, a specific monitor, the monitor
  under the mouse, or all monitors at once.
- Delayed capture with countdown.
- Post-capture actions: save, copy image, copy path, open folder, run a script.
- English and Romanian from the start (`--lang ro`).
- Portable mode: put an empty `portable.flag` file next to the app.
- No telemetry, no network access.

**Known limitations**
- No graphical interface yet (coming in 0.2 / M1). Use the command line.
- Captures do not include the mouse cursor yet.

## Technical release notes

- Architecture: headless core + optional UI; see `docs/ARCHITECTURE.md`.
- Dependencies: Pillow only (PySide6 optional, not used yet). See `docs/DEPENDENCIES.md`.
- Win32 integration via `ctypes`: GDI capture with per-monitor DPI v2,
  `RegisterHotKey` listener thread, CF_DIB clipboard.
- Windows CI on Python 3.10 and 3.12 with real capture / hotkey / clipboard tests.

## Test checklists

### Smoke test (5 min)
```
pip install -e .
python -m screenpilot version
python -m screenpilot monitors
python -m screenpilot capture all
```
- [ ] Monitors listed with correct resolution and the primary one marked.
- [ ] A PNG appears in `Pictures\ScreenPilot` and is also in the clipboard (paste in Paint).

### Functional test (15 min)
- [ ] `python -m screenpilot --lang ro monitors` — Romanian text, diacritics shown correctly.
- [ ] `capture region --rect 0,0,800,600` — exactly 800×600 px.
- [ ] `capture window` — the active window only, no shadow border.
- [ ] `capture current` with the mouse on the second monitor — that monitor only.
- [ ] `capture all --delay 5` — countdown 5…1, then capture (open a menu during the countdown: it must appear).
- [ ] `capture monitor --index 9` — clean error message, no traceback.
- [ ] `python -m screenpilot hotkeys` — default bindings listed.

### Full validation
- [ ] Mixed DPI (laptop 150 % + external 100 %): region spanning both monitors is sharp and correctly aligned.
- [ ] Monitor placed left of / above primary (negative coordinates) captured correctly.
- [ ] Portable mode: `portable.flag` next to the checkout → files go to `UserData\`.
- [ ] Corrupt `settings.json` → app starts, backup `settings.corrupt.json` created.
- [ ] Log file in `%LOCALAPPDATA%\ScreenPilot\logs` contains no personal data beyond file paths.
