# Release 0.7.0 — Video editor

## User release notes

**Edit a recording afterwards**
- Open the editor from:
  - the **✎ Edit** button on the card shown after a recording;
  - or *tray › Tools › Edit a video…* (any MP4, MKV, MOV, AVI, WebM or GIF).
- **Cut the start and the end**:
  - drag the grey handles on the timeline;
  - or move the red line and click *Start here* / *End here* (keys **I** / **O**);
  - *Keep everything* undoes the cut.
- **Annotations with a time range**:
  - **numbered step** (click), **arrow**, **rectangle**, **highlight**, **text**;
  - **blur**, to hide e-mails, names or numbers only for the seconds they are visible.
  - A new annotation appears at the red line and lasts *New annotations last* seconds (3 s by default).
  - On the timeline, each annotation is a coloured bar:
    - drag it to show the annotation earlier or later;
    - drag its ends to change when it appears and disappears;
    - or type the times in *From / to*.
  - Steps are numbered in the order they appear in the video. Moving a step earlier renumbers the others.
  - Select an annotation and click a colour to recolour it. Del deletes it. Ctrl+Z / Ctrl+Y undo and redo.
- **Preview**:
  - Space plays and pauses; ← / → move 0.1 s (with Shift, 1 s); Home / End;
  - or click anywhere on the timeline.
  - The preview plays smoothly enough to check timings. The saved video is full quality.
- **Save video** (Ctrl+S):
  - a new file next to the original, `<name>_edited.mp4` (or `.gif`); the original is never changed;
  - a progress bar shows while it saves, and *Cancel* leaves no file behind;
  - then *Show in folder* opens Explorer on it.
- **Save project**: cuts and annotations as a `.json` file, to continue later.
- MP4 editing needs FFmpeg. GIFs can be edited without it.
- Your administrator can turn video editing off (`video_edit`).

**Command line (and Autopilot)**
- `python -m screenpilot video-info demo.mp4`
- `python -m screenpilot video-edit demo.mp4 --trim 1.5,12 --step 2,5,400,300 --text 2,5,430,280,"Click here" --blur 0,12,10,10,300,40`
- `python -m screenpilot video-edit demo.screenpilot.json` exports a saved project.

## Technical release notes
- New engine `screenpilot.videoedit`:
  - `model`: `VideoProject` (trim, `TimedAnnotation`s with source-timeline times, undo/redo, `begin_change` / `end_change` for drags, `step_numbers()` by time, `active_at()`, `in_output()`, JSON `to_dict` / `apply_dict`), `assign_lanes()`, `format_time()`.
  - `media`:
    - `parse_info()` reads `ffmpeg -i` output;
    - `FfmpegFrameReader` (input seek, rgb24 on stdout) and `GifReader` (Pillow, LRU);
    - `AnnotationPainter` (cached RGBA patches by the editor renderer) and `blur_region()`.
  - `export`:
    - `build_filter()`: blur = `split` / `crop` / `boxblur` / `overlay`; PNG overlays get the BT.709 conversion; `enable='between(t,a,b)'`;
    - `export_command()`: `-ss`/`-t` input seek, `-map 0:a?`, AAC, `-progress pipe:1`;
    - `export_mp4()`: `.part` + rename, cancel kills FFmpeg;
    - `export_gif()`: Pillow, extra frames where annotations change inside a long frame.
  - `service.VideoEditService` = `app.video`: `open`, `open_project_file`, `reader`, `preview`, `default_output`, `export`. If the encoder fails, the export is retried once with libx264.
- New event `video.exported`, policy feature `video_edit`, action `app.edit_video` (tray › Tools, unassigned hotkey), setting `video.annotation_seconds`.
- CLI `video-info`, `video-edit`.
- Editor: public `hit_shape()`. `PillowGifSink.extend_to()`. `IconButton.set_icon()`. `AppController.open_video_editor()`. Shutdown closes editors without the "discard?" question.
- UI: new `ui.video_editor` with `VideoEditorWindow`, `VideoCanvas`, `Timeline` and `FrameLoader` (worker thread, newest request wins). The result card has an *Edit* button.
- Tests: `tests/test_videoedit.py` (model, info parsing, filter graph, progress, GIF export without FFmpeg, real MP4 export with trim, step, rectangle, blur and audio, cancel, CLI), UI tests for the editor and the result card. No new dependencies.

## Test checklist
- [ ] Record 15 s of Excel (Ctrl+Shift+9), then click ✎ on the result card: the editor opens on the first frame.
- [ ] Drag the left grey handle to 3 s and the right one to 12 s. *Kept* shows 00:03.0 – 00:12.0.
- [ ] At 4 s, click a step, then draw an arrow and a text. At 8 s, click another step: it is number 2.
- [ ] Drag the first step's bar after the second: the numbers swap.
- [ ] Draw a blur over a cell with a name, from 3 s to 12 s.
- [ ] Space plays: annotations appear and disappear at their times.
- [ ] *Save video*: the progress bar fills. `<name>_edited.mp4` is 9 s long, with sound, and the annotations are at the right times. The original is unchanged.
- [ ] *Cancel* during a save of a long video: no `_edited` file is left.
- [ ] Edit a GIF recording (Ctrl+Shift+8): it works the same and gives `<name>_edited.gif`.
- [ ] *Save project*, close, then `python -m screenpilot video-edit <file>.screenpilot.json`: same result.
- [ ] Close with unsaved edits: you are asked before anything is lost.
