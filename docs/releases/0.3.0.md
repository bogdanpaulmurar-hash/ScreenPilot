# Release 0.3.0 — Modern UI

## User release notes

**New**
- Fluent / Windows 11 look: light and dark themes (follow Windows or choose), your Windows accent colour, new icons.
- **Capture Hub** home window: big capture tiles, quick options (delay, copy, save, preview) and recent captures.
- **Edge capture bar**: a slim handle at the top of the screen; point at it to open the capture menu. Drag it along the edge, hide it from its own menu or in Settings.
- **Action bar in the selector**: after selecting, choose Capture (Enter), Copy only (Ctrl+C), Save as (Ctrl+S) or Pin (P).
- **Quick preview** after each capture: copy, save as, pin, show in folder — and drag the image straight into Outlook, Teams or Word.
- **Pin to screen**: keep a capture floating above all windows; wheel to zoom, Ctrl+wheel for transparency, Esc to close.
- Settings redesigned with a sidebar and cards.

**Known limitations**
- Edit and Extract text buttons are placeholders (coming in the next milestones).
- The edge bar sits on the primary monitor.

## Technical release notes
- `ui.theme` (design tokens, ThemeManager), `ui.icons` (original inline SVG icons, no icon pack), `ui.widgets`, `ui.hub`, `ui.preview`, `ui.edge_bar`.
- Controller: `captured` signal, `busy`, `hide_chrome()`; selector emits `(Rect, action)`.
- New settings: `general.theme`, `general.edge_bar`, `general.edge_bar_position`, `capture.show_preview`.

## Test checklists

### Smoke (5 min)
- [ ] Start: the hub opens; tiles show your shortcuts.
- [ ] Point at the top edge: the bar slides out; click Region; the bar is not in the capture.
- [ ] Select an area: the action bar appears; press Enter: the preview card appears bottom-right.

### Functional (15 min)
- [ ] Drag the preview thumbnail into Outlook/Teams/Word: the image is inserted.
- [ ] Press P in the selector: the capture is pinned; zoom with the wheel; Esc closes.
- [ ] Settings › General › App theme: switch light/dark; all windows change at once.
- [ ] Windows dark mode on/off with theme "Use Windows setting": ScreenPilot follows.
- [ ] Hub chips: untick Save → captures are only copied (preview says "Copied").
- [ ] Edge bar: drag it to the right; restart the app; it keeps its position.

### Full validation
- [ ] High-contrast / 150 % scaling: texts readable, nothing clipped.
- [ ] Two monitors: pin opens exactly where the capture was taken.
