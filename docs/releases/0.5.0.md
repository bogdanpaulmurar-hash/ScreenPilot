# Release 0.5.0 — Editor, OCR, documentation and recording

## User release notes

**Capture**
- **Capture modes**: each mode has its own shortcut, its own selector border colour, and its own action for Enter. Region (accent colour), Capture + edit **Ctrl+Shift+E** (magenta), Number steps **Ctrl+Shift+N** (green), Scrolling **Ctrl+Shift+6** (orange), Copy only (purple), Pin (teal), Extract text **Ctrl+Shift+O** (gold). Colours, border thickness and dimming are set in *Settings › Capture modes*.
- **Mouse pointer** in captures (Settings › Capture).
- **Colour picker** (**Ctrl+Shift+C**): click a pixel and its HEX code is copied.
- **Ruler** (**Ctrl+Shift+M**): select an area; its size is copied (e.g. `640 × 480 px`).
- **Interval capture** (tray › Tools): captures the same area every N seconds; *Stop* is in the tray.
- **Copy a recent capture** from the tray menu.

**Editor** (Enter in *Capture + edit*, or *Edit* on the preview or in History)
- Arrow, line, rectangle, ellipse, highlighter, text, step numbers, blur, pixelate, spotlight and crop.
- One-key tools, undo/redo, colour and width; copy, save, or save as.
- **Auto-blur sensitive data**: detects emails, phone numbers, IBANs, card numbers, CNP and IP addresses using OCR, then blurs them.

**OCR**
- Select an area with **Ctrl+Shift+O** (or press **T** in the selector). The text is copied to the clipboard and shown in a window where you can edit it and export it as TXT or Markdown.
- Uses the OCR engine built into Windows, so nothing needs installing. Tesseract is optional.

**Documentation**
- **Procedure recording** (**Ctrl+Shift+P**): every capture becomes a step. In the procedure window you can reorder steps, add titles and descriptions, or edit images. Export to **Word (.docx)**, **PDF**, **HTML** or **Markdown**.
- **Watermark** (optional, off by default): text such as `{user} · {date} {time}`, with position and opacity.

**Screen recording (new)**
- **Record video**: **Ctrl+Shift+9**. **Record GIF**: **Ctrl+Shift+8**. Both are also in the hub (*Video*, *GIF*), the edge bar (*Record*) and the tray. Press **R** in any selector to record the selected area.
- Select an area, a window (click it) or a whole screen. A countdown runs, then a red frame marks the recorded area.
- The control bar shows a timer and has **Pause/Resume**, **Zoom** (follows the cursor), **Stop** and **Discard**. Pressing the same shortcut again also stops the recording. The frame and bar never appear in the video.
- **Cursor highlight** and **click ripples** (blue for left click, red for right click), on by default.
- **MP4** (H.264) with **microphone** and/or **computer sound** when FFmpeg is available. MP4 uses the graphics card (NVIDIA / Intel / AMD) automatically when possible. Without FFmpeg, recordings are saved as GIF, with a clear message.
- The result card has **Play**, **Folder**, **Copy path** and **Make a GIF** (high-quality palette).
- Settings › Recording covers: format, frame rate, quality, encoder, audio devices (*Detect* button), effects, countdown, automatic stop, GIF settings, folder and FFmpeg path.

**Diagnostics**
- The **timing journal** (Settings › Diagnostics) shows how long each operation took: last, median, p95 and max.
- **Export diagnostics** (tray or Settings) creates a single .zip file to send when something goes wrong. It contains logs, the error log, crash reports, timings, settings and system information, including FFmpeg detection. It does not contain captures.
- **Detailed logging** switch.

**Install without an .exe (new)**
- `powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Autostart`: per user, no admin rights.
  - Creates a private venv in `%LOCALAPPDATA%\ScreenPilot\venv`, so ScreenPilot never interferes with other Python apps.
  - Adds a Start-menu shortcut with the ScreenPilot icon and optionally the Windows autostart entry (HKCU Run).
- Runs with `pythonw.exe`: no console window, only the tray icon. It has its own taskbar button and icon (AppUserModelID), and only one instance runs at a time.
- **Start with Windows** switch in Settings › General.
- New icon (viewfinder + record dot), used in the tray, taskbar, windows and shortcut.

**For IT**
- `policy.json` (in `%ProgramData%\ScreenPilot` or the application folder) can lock settings and disable features:
  - `run_script`, `edge_bar`, `scrolling`, `recording`, `record_audio`, `ocr`, `pin`, `watermark_off`, `export_diagnostics`.
- The PyInstaller package (GitHub › Releases › *nightly*) is kept only as a build check. **The recommended install is the Python script above**, because unsigned executables are often quarantined by antivirus software.
- FFmpeg is **not bundled**. To enable MP4 and sound, install an approved build:
  - `winget install Gyan.FFmpeg`, or
  - put `ffmpeg.exe` next to `ScreenPilot.exe`, or
  - set its path in Settings (this setting can be locked by policy).

**Known limitations**
- Windows OCR for Romanian or German needs that Windows language pack installed.
- Computer sound needs a loopback device such as *Stereo Mix*. Native WASAPI loopback is planned.
- Zoom costs about 20–40 ms per 1080p frame. During zoom, the video stays in sync by repeating frames.
- GIF recordings are capped by memory (about 300 MB of frames). Use MP4 for long recordings.
- DRM-protected video (Netflix and similar) records as black. This is by design in Windows.

## Technical release notes
- `core.diagnostics` (perf.jsonl, errors.log, crash handlers, faulthandler, export bundle) and `core.policy`.
- `capture.profiles` (modes), `editor.document` (shapes, render, undo), `editor.watermark`.
- `ocr` (Windows.Media.Ocr via PowerShell, Tesseract TSV, sensitive-data validators: Luhn, IBAN, CNP).
- `docs` (ProcedureSession, hand-written OOXML .docx, HTML, Markdown; PDF through Qt).
- **`recording`** (new):
  - `Recorder` thread: grab → effects → sink. Recording time excludes pauses.
  - `FfmpegSink`:
    - raw BGRA piped to an external ffmpeg at a constant frame rate, filling missed slots with the previous frame;
    - DirectShow audio inputs are opened first; encoder start-up is excluded from the timeline;
    - pause ends the current segment, and segments are joined with the concat demuxer without re-encoding;
    - hardware encoders (`h264_nvenc`, `h264_qsv`, `h264_amf`, `h264_mf`) are verified with a test encode, then `libx264`, `libopenh264`, `mpeg4`.
  - `PillowGifSink`: duplicate frames are merged into longer durations; memory is capped.
  - `Win32FrameSource`: a persistent DIB section; no `CAPTUREBLT`, to avoid cursor flicker; cursor drawn with `DrawIconEx`; buttons polled with `GetAsyncKeyState`, with no input hooks.
  - `EffectRenderer`: highlight and ripples update only a small patch of the frame; zoom eases in and out.
  - `RecordingService` on the app (`app.recording`), so Autopilot can call `app.recording.start(rect).stop(wait=True)`.
  - Events: `recording.state`, `recording.finished`, `recording.failed`, `recording.cancelled`, `recording.saved`.
- UI: `ui.recording`:
  - `RecordingController`, `RecordingFrame`, `RecordingBar` and `RecordingResultCard`;
  - `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` keeps the frame and bar out of captures.
- CLI: `screenpilot record --rect x,y,w,h --seconds N [--format mp4|gif] [--out file]`, `screenpilot record-info`.
- New settings `recording.*`, new policy feature `record_audio`, new hotkeys `record.video`, `record.gif`, and optional `record.pause`, `record.zoom`.
- Dependency review: FFmpeg runs as an optional external process and is never linked or bundled (see DEPENDENCIES.md).
- Measured performance (cloud CPU; laptops are usually faster):
  - effects patch: about 6 ms per 1080p frame;
  - GIF frame: about 34 ms at 1080p;
  - frame detection: 38 ms at 1080p;
  - editor render: about 47 ms at 1080p.

## Test checklists

### Smoke (5 min)
- [ ] `scripts\install.ps1 -Autostart`: no console window stays open, the ScreenPilot icon appears in the tray, and Start menu › ScreenPilot exists. Ctrl+Shift+1 captures a region.
- [ ] Sign out and back in: ScreenPilot starts in the tray. The hub does not open.
- [ ] Ctrl+Shift+8, select an area, wait for the countdown, move the mouse and click a few times, then press Ctrl+Shift+8 again. A GIF is saved and the result card opens; *Play* shows ripples at the clicks.
- [ ] Settings › Recording shows the FFmpeg status. With FFmpeg: Ctrl+Shift+9 records an MP4 that plays in the Windows player.
- [ ] Tray › Export diagnostics creates a .zip file.

### Functional (15 min)
- [ ] Recording: pause for 5 s, then resume. The video has no 5 s gap and its length matches the timer.
- [ ] Zoom button during a recording: the video zooms smoothly towards the cursor and back.
- [ ] Discard (✕): no file is left. Esc during the countdown cancels.
- [ ] Settings › Recording › Detect lists your microphone. Choose it, record 10 s while speaking: voice and image are in sync.
- [ ] *Make a GIF* on an MP4 creates a GIF next to it.
- [ ] Capture + edit (Ctrl+Shift+E): arrow, text, blur, crop; *Copy* puts the edited image on the clipboard.
- [ ] Auto-blur on a screen showing an email address and an IBAN: both are blurred.
- [ ] Ctrl+Shift+O on a paragraph: the text is in the clipboard.
- [ ] Ctrl+Shift+P, take 3 captures, then *Finish*: export Word and PDF and open both.
- [ ] Turn on the watermark: it appears on new captures.

### Full validation
- [ ] 150 % scaling and two monitors: the recording frame sits exactly around the area on both monitors.
- [ ] Full-screen 1080p MP4 at 30 fps for 2 minutes: Settings › Diagnostics › `recording.session` shows capture fps close to 30, and few duplicated frames.
- [ ] Hardware encoder: in the log, `Encoder h264_nvenc|qsv|amf works` matches your GPU.
- [ ] `policy.json` with `"disabled_features": ["recording"]`: the Video/GIF tiles and hotkeys show "disabled by your administrator"; with `record_audio`, the audio choices are greyed out.
- [ ] A capture taken during a recording does not show the red frame or the control bar.
- [ ] With other Python apps running: the ScreenPilot taskbar button has its own icon (not grouped under Python); Task Manager › Startup apps lists ScreenPilot.
- [ ] `scripts\uninstall.ps1` removes the shortcut, the autostart entry and the venv; your captures stay.
