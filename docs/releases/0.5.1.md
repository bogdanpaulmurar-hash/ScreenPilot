# Release 0.5.1 — Fixes from the first real-use round

## User release notes

**Recording**
- **FFmpeg is found without restarting ScreenPilot.** If you install it while ScreenPilot runs (for example `winget install Gyan.FFmpeg`), the next recording uses it.
  - ScreenPilot now also looks in the winget, Chocolatey and Scoop folders.
- When FFmpeg is missing, the *Recording as GIF* message can be **clicked**: it opens *Settings › Recording*.
  - There, *Copy install command* copies `winget install --id Gyan.FFmpeg -e`.
  - You can turn the message off (*Tell me when a video is saved as GIF*).
- **GIF quality**: GIFs keep the full screen resolution (up to 1920 px wide by default instead of 960) at 15 fps.
  - Text stays sharp: screen content is saved without colour loss.
  - GIFs are written to disk while you record, so they are no longer limited to about one minute.
  - Your old GIF settings are updated only if you never changed them.
- **Esc during a recording** pauses it and asks: *Continue*, *Stop and save* or *Discard*.
  - Can be turned off in *Settings › Recording* (*Esc pauses the recording*).

**Capture**
- **Much faster selector on Excel, Google Sheets and other tables.**
  - The automatic frame detection could take seconds for every mouse move on a grid. That froze the selector and Windows sometimes hid the screen. It now takes a few milliseconds.
  - The selector also takes the keyboard focus reliably, so arrows, Enter and Esc work right away.
- **Esc cancels any capture step**: the selector, the countdown and interval capture. It works even when another app has the keyboard.
- **Esc during a scrolling capture** pauses it and asks: *Continue*, *Stop and keep* or *Discard*.
- **New setting: *Show the action bar after selecting*** (*Settings › Capture*).
  - Off: the area is captured as soon as you release the mouse.
  - Each mode does its usual thing (Region saves and copies, *Capture + edit* opens the editor, and so on).
- **New setting: *Region capture result*** (*Settings › Capture*): *after-capture actions* (save + copy) or *Copy to clipboard only*.
- **Lossless paste**: copied captures are also placed on the clipboard as PNG. Teams, Outlook, Word and browsers then paste the image without recompressing it.
- **Show in folder** opens the folder where the file was saved, also when the path contains spaces (OneDrive, Desktop, …).

**Editor**
- **Copy & close** button in the editor and in *Number steps* (**Ctrl+Shift+Enter**). It copies the image and closes the editor, without saving.
  - *Copy* keeps the editor open, and *Done* still runs your after-capture actions.
  - When you edit a procedure step, *Copy & close* also keeps the edit in the step.
- **Open editor** (hub ✎ button, tray › Tools, or your own shortcut) now lets you choose what to edit:
  - the **last capture** (also when it was only copied);
  - one of the **10 most recent** captures;
  - the image on the **clipboard**;
  - a **file**;
  - or **All captures…** (the history with search).
  - *Settings › General › Open editor* switches to "open the last capture directly".

## Technical release notes
- `recording.ffmpeg`:
  - `well_known_dirs()` covers WinGet Links/Packages, Chocolatey, Scoop, `Program Files\ffmpeg\bin` and the registry `Path` (HKCU/HKLM).
  - `candidate_paths(..., search_dirs=)` is injectable and de-duplicated.
- `RecordingService.ffmpeg()`:
  - a missing FFmpeg is no longer cached;
  - a found one is re-checked when its file disappears;
  - the probe is reused for the same binary;
  - `ffmpeg_search_dirs` can be injected for tests.
- `recording.gif.PillowGifSink` was rewritten as a streaming writer:
  - patches of the changed bounding box, disposal 1;
  - an exact palette (MAXCOVERAGE) when a patch has ≤ 256 colours, otherwise FASTOCTREE without dithering;
  - Pillow encodes each patch, and `image_block()` re-packs the descriptor, local colour table and LZW data with the patch offset;
  - delays come from the cumulative timeline, so they do not drift;
  - the file is written as `.gif.part` and renamed at the end;
  - caps: 200k frames or 1.5 GB.
- Settings schema **2**:
  - migration `_v1_to_v2` raises `recording.gif_max_width` 960→1920 and `gif_fps` 12→15 only when they still had the old defaults.
  - New keys: `capture.region_action`, `selector.action_bar`, `editor.open_mode`, `recording.esc_pauses`, `recording.gif_fallback_notice`.
- `capture.detect`:
  - candidate pairs are ranked by distance, and both edges of a 1 px line share a rank;
  - combinations are visited by total rank;
  - side tests are memoised;
  - there is a 25 ms budget, `MAX_BOXES = 160` and a per-point LRU cache in `FrameFinder`.
  - A 1080p grid went from ~13.5 s to ~3 ms per point.
- `capture.scrolling.capture_scrolling(on_stop=, sleep=)`: Esc asks `continue` / `stop` / `cancel`. `CaptureService.capture_scrolling` returns `(None, "cancelled")` and publishes `capture.cancelled` with `mode="scrolling"`.
- New `platform.win32_window`:
  - `force_foreground` (AttachThreadInput + SetForegroundWindow);
  - `disable_ghosting`;
  - `key_down` (GetAsyncKeyState);
  - `reveal_in_explorer` (SHOpenFolderAndSelectItems, with a correctly quoted `explorer /select,"…"` fallback).
- New `platform.keys.KeyLatch`.
- `platform.dib.png_from_image`. `Win32Clipboard.set_image` sets `CF_DIB` and the registered `PNG` format in one clipboard session.
- UI:
  - `AppController`: `notify_action` signal (clickable tray messages), `watch_escape` / `escape_pressed`, `ask_continue`, `last_result` / `last_capture()`, `show_editor_picker`, `clipboard_capture`, `open_image_file`, `show_settings(page)`.
  - New `ui.editor_picker.EditorPicker`.
  - `EditorWindow(on_copy_close=)` and `copy_and_close()` in both editors.
  - `SelectorStyle.action_bar`; `SettingsDialog.show_page()`.
- No new dependencies.

## Test checklists

### Smoke (5 min)
- [ ] Excel with a large sheet, then Ctrl+Shift+1: the frame follows the mouse without lag on all 3 monitors, and no screen disappears.
  - Arrows move the cursor or the selection right away.
  - Esc closes everything.
- [ ] Same in Google Sheets in the browser.
- [ ] Without FFmpeg, Ctrl+Shift+9: the *Recording as GIF* message appears. Click it and *Settings › Recording* opens.
- [ ] Run `winget install --id Gyan.FFmpeg -e` while ScreenPilot keeps running, then Ctrl+Shift+9 again: you get an MP4, with no restart.
- [ ] Save a capture with *Save as* into a folder with spaces in its name, then click 📁 on the preview: that folder opens with the file selected.

### Functional (15 min)
- [ ] GIF recording of a full 1080p screen for 2 minutes: the text is sharp and the file is not cut at about 1 minute.
- [ ] Esc during a recording: the question appears and the timer stops.
  - *Continue*: the video has no gap.
  - *Stop and save*: you get the result card.
  - *Discard*: no file is left.
- [ ] Esc during a scrolling capture: *Stop and keep* gives the partial image, and *Discard* gives nothing.
- [ ] Esc during the 3-second countdown of a delayed capture: it is cancelled.
- [ ] Settings › Capture › turn off *Show the action bar*: drag an area and it is captured on release.
- [ ] *Region capture result = Copy only*: Ctrl+Shift+1, select, Enter. The image is on the clipboard and no file is saved.
- [ ] Paste a capture into Teams or Outlook: it looks sharp, with no JPEG blur.
- [ ] Hub ✎ (Open editor): the picker shows the last capture and the recent ones.
  - *From clipboard* works after copying an image in a browser.
  - *All captures…* opens the history.
- [ ] Editor: *Copy & close* closes the editor, the clipboard has the edited image, and nothing new appears in History.
