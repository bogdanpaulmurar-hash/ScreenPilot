# Release 0.7.3 — Esc everywhere, readable FFmpeg errors, a real settings icon

## User release notes
- **Esc closes what a capture opened** and brings you back to the normal screen:
  - quick preview;
  - editor and *Number steps* (if you drew something, it asks first);
  - OCR window, pinned image;
  - video editor (it asks when there are unsaved edits);
  - Capture Hub and History.
  - Recording and scrolling capture still pause and ask.
- These windows now really get the keyboard focus when they open after a hotkey, so Esc and the shortcuts reach them, not the app behind.
- **FFmpeg errors say why.** *"FFmpeg could not encode a test video: …"* shows FFmpeg's own reason. Clicking the message opens *Settings › Recording*.
  - A freshly downloaded `ffmpeg.exe` can be held by the antivirus on its first starts, so ScreenPilot tries the software encoder once more and waits up to 90 s.
  - `python -m screenpilot record-info` lists every encoder with *ok* or the reason it failed.
- The **settings button** shows a gear instead of a sun.

## Technical release notes
- `ui.qt_helpers`:
  - `present(window)`: show, raise, activate, then `force_foreground` in the next event-loop turn. Used for the editor, steps, OCR, pin, single windows, the video editor and the bar editor.
  - `on_escape(window, handler)`: a window-wide shortcut.
- `EditorWindow.escape()` and `StepEditor.escape()`, with `editor_window.confirm_discard()`. `OcrWindow`, `CaptureHub` and `HistoryWindow` close on Esc. The video editor deselects first, then closes.
- `AppController`: `_preview_visible()`; `escape_pressed()` returns `"preview"`; `show_preview()` calls `watch_escape()`.
- `FfmpegInfo`:
  - `errors` holds the last stderr line or timeout per encoder;
  - `works(timeout=)`;
  - `choose_encoder()` tries software encoders even when `-encoders` could not be read, retries timed-out ones with `SLOW_PROBE_TIMEOUT = 90`, and raises with `reason` / `path` params.
- Recording errors use the title `recording.failed.title` (it was "Capture failed") and are clickable.
- Icon `settings` redrawn as a cog.
