# Release 0.7.2 — Know which version you run; your own capture bar

## User release notes

**Installing and updating**
- New **`Install.bat`** (double-click) and **`Uninstall.bat`** in the main folder.
- The installer shows the version it installs and, at the end, `Installed: ScreenPilot 0.7.2`.
- It warns when the folder is **behind GitHub** (you would install an old version) or has **local changes** that make `git pull` stop with "Aborting". It also tells you the fix: `git stash --include-untracked`, then `git pull`.
- It builds from a temporary copy, so it also works from Google Drive or OneDrive folders. A normal folder such as `%USERPROFILE%\Dev\ScreenPilot` is still the better place for a git repository.
- **FFmpeg** (for MP4):
  - if winget fails (for example `0x8a15000f`, "data required by the source is missing"), the installer refreshes the winget source and tries once more;
  - then it downloads the official build from gyan.dev, checks its SHA-256 and puts it in `%LOCALAPPDATA%\ScreenPilot\ffmpeg`, with no admin rights;
  - ScreenPilot finds it there automatically.
- Desktop shortcut, and the uninstaller removes it.

**Which version is running**
- Tray icon tooltip: second line `v0.7.2`.
- Capture Hub: bottom-right corner.
- *Settings › General*: at the bottom.

**Capture bar (top of the screen): your own buttons**
- *Settings › General › Capture bar buttons › Customise…*, or right-click the bar.
- Add any of: Region, Window, Screen, All screens, Scrolling, Delayed, Capture + edit, Steps, Copy, Pin, Repeat, OCR, Video, GIF, Procedure, Colour, Ruler, Editor, Edit video, Hub, History, Settings, Hide.
- Order them by dragging or with *Move up / down*, and add separators.
- *Default buttons* brings back the original set.

## Technical release notes
- `scripts/install.ps1`:
  - new switches: `-Ffmpeg`, `-DesktopShortcut`, `-SkipGitCheck`;
  - `Test-GitState` runs `git fetch`, then reports how many commits HEAD is behind its upstream and the porcelain status;
  - FFmpeg: `Find-Ffmpeg`, `Install-Ffmpeg` (winget with `--scope user`, a `source update` retry, then `Install-FfmpegFromGyan` with the published `.sha256`);
  - builds from `%TEMP%\screenpilot-src-*` (`pyproject.toml`, `README.md`, `src`) with `--force-reinstall --no-deps`, then `[ui]`;
  - prints `screenpilot version` at the end and warns when it does not match;
  - the git and winget calls run with `ErrorActionPreference=Continue`, because Windows PowerShell turns native stderr into errors;
  - the script stays ASCII-only.
- `uninstall.ps1` removes the Desktop shortcut. `.gitattributes` keeps `.bat`, `.cmd` and `.ps1` files as CRLF.
- New `ui.edge_items` (Qt-free catalogue, `DEFAULT_EDGE_BUTTONS`, `edge_buttons()`) and `ui.edge_bar_editor.EdgeBarEditor`.
- `EdgeBar._build_buttons()` rebuilds the buttons on `general.edge_bar_buttons` changes, with a Retranslator per build so the old bindings are disposed. The bar also has a context menu.
- `AppController.customize_edge_bar()`.
- Settings: `general.edge_bar_buttons` (`[]` = default).
- Version labels: `TrayIcon` tooltip, `CaptureHub.version_label`, `SettingsDialog.version_label`.
- Tests: `tests/test_edge_items.py`, UI tests for the editor, the bar rebuild and the version labels. No new dependencies.
