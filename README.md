# ScreenPilot

Lightweight, enterprise-friendly screenshot, screen recording and
documentation platform for Windows — written in Python.

- **Documentation-first**: capture → annotate → step-by-step documents (roadmap).
- **Enterprise-safe**: no telemetry, no network access, minimal dependencies,
  no keyboard hooks, portable mode.
- **Bilingual**: English and Romanian from day one; new languages are a JSON file.
- **Automation-ready**: a headless core with a stable API for Autopilot.

> Status: **0.7.5** — capture (modes, frame detection, scrolling, steps), editor,
> OCR with auto-blur, procedure documents (Word/PDF/HTML/Markdown), screen
> recording (MP4/GIF) with live annotations, video editor (trim, timed annotations), diagnostics and IT policy. See [docs/ROADMAP.md](docs/ROADMAP.md),
> the [release notes](docs/releases/0.7.4.md) and the [UI screenshots](../../tree/ci-screenshots) generated by CI.
>
> **Portable build**: GitHub › Releases › *nightly* → unzip → `ScreenPilot.exe`.

## Install (Windows, Python 3.10+, no admin rights, no .exe)

Clone the repository **outside Google Drive / OneDrive** (for example
`%USERPROFILE%\Dev\ScreenPilot`), then double-click **`Install.bat`**. It runs:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Autostart -Ffmpeg -DesktopShortcut
```

To update: `git pull`, then `Install.bat` again. The installer prints the version it
installs (`Installed: ScreenPilot x.y.z`) and warns when the folder is behind GitHub or
has local changes that block `git pull`. The running version is shown in the tray
tooltip, at the bottom of the Capture Hub and in *Settings › General*.

* ScreenPilot gets its **own private Python environment** in
  `%LOCALAPPDATA%\ScreenPilot\venv` — it never touches your other Python apps.
* It runs with `pythonw.exe`: **no console window**, only the tray icon, with
  its own taskbar identity and icon.
* `-Autostart` starts it with Windows (also a switch in Settings › General).
* `-Ffmpeg` installs FFmpeg for MP4 recordings: with winget, or when winget fails,
  the official essentials build from gyan.dev (SHA-256 checked) into
  `%LOCALAPPDATA%\ScreenPilot\ffmpeg`. Optional: GIF recording works without it.
* Start menu › **ScreenPilot**. Uninstall: `scripts\uninstall.ps1`.

## Development (from a checkout)

```powershell
git clone https://github.com/bogdanpaulmurar-hash/ScreenPilot.git
cd ScreenPilot
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[ui]"

python -m screenpilot gui          # tray app: Ctrl+Shift+1 = capture a region

# command line (no UI needed)
python -m screenpilot monitors
python -m screenpilot capture region --rect 0,0,800,600
python -m screenpilot capture all --delay 3
python -m screenpilot --lang ro hotkeys
python -m screenpilot record --rect 0,0,1280,720 --seconds 10   # MP4 (ffmpeg) or GIF
python -m screenpilot record-info                               # ffmpeg / encoder / audio check
```

MP4 recording with sound uses an **optional, external FFmpeg** (not bundled):
`winget install Gyan.FFmpeg`, or put `ffmpeg.exe` next to the app. Without it,
recordings are saved as GIF.

Captures go to `Pictures\ScreenPilot` and are copied to the clipboard
(configurable). Put an empty `portable.flag` file in the folder to keep all
data next to the app.

## Run an action in the running app (shortcuts, scripts, DevPilot)

```powershell
%LOCALAPPDATA%\ScreenPilot\venv\Scripts\pythonw.exe -m screenpilot action capture.region
python -m screenpilot action --list
```

Only one ScreenPilot runs at a time: `action <id>` (and a second `gui` start)
hands the request to the running app through a local, per-user channel and
exits. If ScreenPilot is not running yet, it is started first.

**DevPilot**: use `%LOCALAPPDATA%\ScreenPilot\venv\Scripts\pythonw.exe` as the
interpreter (DevPilot's ScreenPilot preset does this automatically). The hub
options come from [`devpilot.tool.json`](devpilot.tool.json). When DevPilot
owns the tray and the autostart (`DEVPILOT_SUPPRESS`), ScreenPilot shows no tray
icon of its own (messages appear as small cards) and leaves the Windows
autostart entry to DevPilot.

## Use from Python / Autopilot

```python
from screenpilot.app import create_app
from screenpilot.capture import Rect

app = create_app()
result = app.capture.capture_region(Rect(0, 0, 800, 600))
app.run_after_capture(result)  # the user's configured action chain
```
